# 📊 E-Commerce Sales Dashboard (Excel Project)

## 📌 Project Overview
This project involves creating an interactive dashboard in Microsoft Excel to analyze sales performance, profit trends, and order data for an e-commerce business.

---

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- VLOOKUP
- Charts & Graphs
- Slicers

---

## ⚙️ Key Features
- Interactive dashboard for real-time data analysis
- KPI tracking (Sales, Profit, Quantity, Orders)
- Data cleaning and preprocessing
- Dynamic filtering using slicers

---

## 📊 Dashboard Insights
- Analyzed monthly sales and profit trends
- Evaluated category-wise performance
- Identified top-performing products and regions
- Monitored profit margins and growth rates

---

## 🔍 Visualizations
- Bar charts for sales and profit comparison
- Pie charts for category distribution
- Map chart for region-wise sales
- KPI cards for quick insights

---

## 🚀 Conclusion
This project highlights strong skills in Excel data analysis and visualization, enabling effective business decision-making through interactive dashboards.
